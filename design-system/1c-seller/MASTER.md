# 1C Seller — Design System (MASTER)

Источник истины для визуального стиля. Основан на текущем `static/css/main.css`
(идентичность сохраняем), плюс исправления по итогам аудита.

## 1. Характер

**Trust & Authority + Conversion** — B2B-сервис по 1С: спокойный, технически
компетентный, без «агентской» игривости.
Идентичность: **тёмно-синий (navy) + янтарный акцент**, шрифт Manrope (есть кириллица).

Не делаем: фиолетово-розовые градиенты, эмодзи вместо иконок, декоративную анимацию ради анимации.

## 2. Цвет (токены)

Оставляем существующие имена, добавляем недостающие семантические.

| Токен | Значение | Роль |
|---|---|---|
| `--color-dark` | `#0f172a` | шапка, hero, тёмные секции, текст на жёлтой кнопке |
| `--color-dark-2` | `#1e293b` | карточки на тёмном |
| `--color-bg` / `--color-bg-alt` | `#f8fafc` / `#f1f5f9` | фон страницы / чередующиеся секции |
| `--color-text` | `#334155` | основной текст (≥ 7:1 на bg) |
| `--color-text-light` | **`#475569`** (было `#64748b`) | вторичный текст, ≥ 4.5:1 на `bg-alt` |
| `--color-primary` | `#eab308` | **только фон кнопок/бейджей/линий**, НЕ цвет текста на светлом |
| `--color-primary-dark` | `#ca8a04` | hover; текст на светлом — только `#a16207` (новый `--color-primary-text`) |
| `--color-accent` | `#3b82f6` → **`#0369a1`** для ссылок на светлом | ссылки (синий #3b82f6 на светлом даёт ~3.5:1 — не проходит AA) |
| `--color-success` / `--color-danger` | `#16a34a` / `#b91c1c` | вынести из хардкода в токены |
| `--color-focus` | `#0369a1` (на тёмном — `#fbbf24`) | focus ring |

Правило: в компонентах нет «сырых» hex — только токены (сейчас ~25 hex-литералов вне `:root`).

## 3. Типографика

- Шрифт: Manrope 400/500/600/700/800 (оставить; добавить `font-display: swap` — уже есть в URL).
- Шкала (rem, база 16px): 12 / 14 / 16 / 18 / 20 / 24 / 32 / 48. Мельче 12px не использовать
  (сейчас есть 11px в `.cert-item figcaption`).
- Заголовки: weight 800, `letter-spacing: -0.02em`, `line-height: 1.15–1.25`, `text-wrap: balance`.
- Основной текст: 16–18px, `line-height: 1.6–1.7`, ширина строки ≤ 70ch (блог, юр. страницы).
- Моно (код 1С, запросы): единый стек `ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`
  (сейчас два разных стека — строки 1227 и 1729).

## 4. Отступы, радиусы, тени

- Шкала отступов 4-базы: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 → токены `--space-1…9`.
- Радиусы: `--radius-sm 10px` (кнопки, поля), `--radius 16px` (карточки), pill 100px (бейджи).
- Тени: `--shadow` (покой), `--shadow-lg` (hover/модалки). Одна глубина на состояние.
- Секции: вертикальный padding 96px desktop / 64px mobile.

## 5. Компоненты

**Кнопки** (`.btn`): primary (янтарный градиент + тёмный текст), outline, ghost (на тёмном).
Min-height 44px (`.btn--sm` сейчас ~38px — поднять). Вместо `transition: all` —
`transition: transform, box-shadow, background-color, border-color`.

**Карточки**: белый фон, `border 1px var(--color-border)`, `--radius`, hover — подъём на 2–4px + `--shadow`.
Единый базовый класс `.card`, от него `.pain-card`, `.service-card`, `.tools-card`, `.blog-card`, `.team-card`
(сейчас у каждого свои копии padding/border/hover).

**Иконки**: SVG-спрайт (Lucide), `stroke-width 1.75`, размер 24px в контейнере 48px с фоном
`rgba(primary,.12)`. Эмодзи 🐌📅🔗⚠️📋 заменить (выглядят по-разному на ОС, нельзя темизировать).

**Формы**: видимые `label` над полем, ошибка под полем (`role="alert"`), `:focus-visible` кольцо 3px,
min-height 44px. Два набора классов (`.form-row/.form-control` и `.form-field/.form-select/.form-textarea`)
свести в один.

**Таблицы цен**: горизонтальный скролл-контейнер на mobile уже есть; добавить `scope="col"` и зебру.

## 6. Движение

- Микро-переходы 150–250ms, ease-out; вход элементов 300–400ms (`fadeUp`), выход быстрее входа.
- Анимировать только `transform`/`opacity`.
- Обязательно:
  ```css
  @media (prefers-reduced-motion: reduce) {
    *, *::before, *::after { animation-duration: .01ms !important; transition-duration: .01ms !important; scroll-behavior: auto !important; }
  }
  ```

## 7. Доступность (обязательный минимум)

- `:focus-visible` для всех интерактивных (сейчас **0** правил; 3 места с `outline: none`).
- Skip-link «Перейти к содержимому» первым в `<body>`.
- Контраст ≥ 4.5:1 (см. токены выше), не передавать смысл только цветом.
- Burger: `aria-expanded`, `aria-controls`; закрытие по Esc.
- Цели касания ≥ 44×44, интервал ≥ 8px.

## 8. Адаптив

Брейкпоинты: 1024 / 768 / 640 → свести к **1024 / 768 / 480**, mobile-first.
Сейчас `@media (max-width: 768px)` встречается 3 раза в разных местах файла — собрать вместе.
Проверять на 375 / 768 / 1024 / 1440, без горизонтального скролла.

## 9. Тёмная тема (опционально, этап 3)

Шапка/hero уже тёмные — основа готова. Через токены: переопределить `--color-bg*`, `--color-text*`,
`--color-border` под `prefers-color-scheme: dark`; жёлтый акцент остаётся.

## 10. Организация CSS

`main.css` — 1815 строк в одном файле. Разбить без сборщика через `@import`/несколько `<link>`:
`tokens.css`, `base.css`, `components.css`, `landing.css`, `tools.css`, `blog.css`.
Инструменты (`calc-*`, `tools-*`, `release-feed`, `task-estimator`) подгружать только на своих страницах.
